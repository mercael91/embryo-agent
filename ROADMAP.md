## Этап 2: Мета-инженерия (после 30 дней автономии)

### Anti-Pattern Miner 🧠

**Идея:** Анализировать чужие закрытые PR (не только свои) и генерировать новые anti-patterns на бесплатных нейросетях.

**Почему мета-инженерия:**
- Level 1: «Я ошибся → запомнил» (текущий уровень)
- **Level 2: «Другие ошибаются → запомнил»** (Anti-Pattern Miner)
- Level 3: «Есть паттерн ошибок → создал гейт» (следующий)

**Архитектура:**

```
┌─────────────────────────────────────────────────┐
│           ANTI-PATTERN MINER (фоновый)          │
│                                                  │
│  1. СКАНИРОВАНИЕ                                 │
│     GitHub: is:pr is:closed is:unmerged          │
│     Фильтр: свежие (<14д), human-комментарий     │
│                                                  │
│  2. ИЗВЛЕЧЕНИЕ                                    │
│     Maintainer-комментарий → reason              │
│                                                  │
│  3. КЛАССИФИКАЦИЯ (Mimo/DeepSeek, $0)            │
│     Категория + severity + гейт-рекомендация     │
│                                                  │
│  4. ВАЛИДАЦИЯ                                    │
│     Не дубликат? Достаточно конкретен?           │
│                                                  │
│  5. ПРИМЕНЕНИЕ                                   │
│     Новый гейт → submission pipeline             │
└─────────────────────────────────────────────────┘
```

**Категории для добычи:**

| Категория | Пример из экосистемы | Гейт |
|---|---|---|
| Slop | «AI-generated, no understanding» | pre-mortem: объясни каждую строку |
| Wrong scope | «Fixes unrelated, touches too many files» | diff-size gate |
| No tests | «New module, no test file» | TDD signal |
| Obvious duplicate | «Already fixed in #123» | check open PRs |
| Style mismatch | «Doesn't follow CONTRIBUTING.md» | read CONTRIBUTING |
| Abandoned | «Reviewer asked change, author disappeared» | response-time monitor |

**Бюджет:** $0 (Xiaomi Mimo / DeepSeek Flash, ~50K токенов/день)
**Место в архитектуре:** `background_worker.py` → `pattern_extractor.py` (Tier 3)

| # | Задача | Критерий | Статус |
|---|--------|----------|--------|
| 2.1 | Anti-Pattern Miner v1 | 10 новых anti-patterns из чужих PR | ⏳ |

## Стратегия PR (обновлено Aug 26)

| Критерий | Порог | Почему |
|----------|-------|--------|
| Maintainer activity | <30 дней на свежих PR | Активный = быстрый ответ |
| Last commit | <7 дней | Проект живой |
| ai-welcome label | Да | Явное приглашение |
| Размер патча | <30 строк (для нового repo) | Тривиальный = быстро |
| Макс 2 на repo | Да | Не спам |
| Макс 10 активных | Да | Не распыляться |

**Таймаут:** 48h → напоминание, 96h → закрыть. Auto-close: 7 дней → auto-reopen если ответ.
